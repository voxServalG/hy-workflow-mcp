# Skills

The package installs exactly three cross-Agent Skills. Their frontmatter descriptions carry complete positive and negative trigger conditions; their short bodies route to one-level references only when those details are needed.

`hy-init` runs on first entry to an unfamiliar repository, an explicit orientation request, or when task-relevant project knowledge is not current. It reads local instructions, manifests, native test configuration, current Git facts, and only applicable protocol sources. It performs no installation, test, remote access, Git mutation, or private-state write.

`hy-verify` runs after substantive changes, on explicit verification requests, before readiness claims, and again after a diff changes. It reads every issued source, performs semantic impact analysis, uses boundary semantics rather than duration to select Small/Medium/Large supplemental checks, executes exact issued argv, and submits current evidence. CLI-issued commands are the minimum, not the maximum.

`hy-capture` runs only for a demonstrated major incident, serious repeated regression, or an explicit request to institutionalize a proven lesson. Authoritative capture requires impact, root cause, a before/after regression oracle, and a stable native command. It edits ordinary incident/invariant Markdown, a native test, and the smallest protocol relation. There is no capture CLI and normal Git review establishes acceptance.

All three Skills degrade without blocking. Missing CLI, protocol, source, or evidence is reported precisely. It may prevent a protocol-backed readiness claim, but it never forces the user to install, reset, approve, reconnect, or repair internal workflow state before the Agent can continue safe work.
